# ✨ Alas de Luz Divina

A responsive landing page for a spiritual wellness business, built with React, TypeScript and Tailwind CSS.

The website allows visitors to learn about Alas de Luz Divina, explore its angelic therapy services, discover Paula's story, read testimonials, and easily book a session through WhatsApp.

---

## 🌿 About the Project

This project was created for a real client with the goal of building a professional online presence for a small business.

The website follows a single-page (landing page) approach to guide visitors naturally through the story of Alas de Luz Divina, its services, and its mission before encouraging them to schedule a therapy session.

In addition to building the website, this project focuses on creating a clear information architecture, reusable React components, responsive design, and an intuitive user experience that reflects the calm and welcoming essence of the brand.

---

## 🎯 Project Goals

- Build a modern and responsive landing page.
- Create a calm and intuitive user experience.
- Showcase the services offered by Alas de Luz Divina.
- Make it easy for visitors to contact the business through WhatsApp.
- Apply React best practices and reusable component architecture.
